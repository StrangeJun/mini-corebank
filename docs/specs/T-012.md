# T-012 상세 명세: 프론트엔드 데모 웹 화면 (`frontend/` React + TypeScript + Vite)

## 1. 목표
D-002([docs/DECISIONS.md](../DECISIONS.md)) 결정에 따라 `frontend/`에 React + TypeScript (Vite) 기반의 깔끔한 1금융권 인터넷뱅킹 데모 대시보드를 구현하여 백엔드의 모든 핵심 기능(마일스톤 1·2)을 브라우저에서 시연할 수 있게 한다.

## 2. 주요 화면 및 기능 구성 (`frontend/`)
1. **인증 화면 (로그인 / 회원가입)**:
   - 회원가입 폼 (`email`, `password`, `name`) 및 로그인 폼
   - 데모 편의를 위해 화면에 기본 관리자 계정(`admin@corebank.com` / `Admin1234!`) 빠른 입력 또는 안내 표시
   - JWT 토큰 관리 및 상단 헤더에 현재 로그인 사용자 이름·권한(`USER` / `ADMIN`)·로그아웃 버튼 표시
2. **내 계좌 대시보드 & 계좌 개설**:
   - 보유 계좌 카드 목록 (계좌번호/마스킹 번호, 현재 잔액 원화 포맷 `1,000,000원`, 상태 배지 `ACTIVE`/`LOCKED`/`CLOSED`, 1회·1일 한도)
   - 신규 원화 계좌 개설 모달/폼 (4~6자리 PIN 설정, 한도 설정) 및 잔액 0원 계좌 해지 버튼
3. **금전 거래 탭 (입금 / 출금 / 즉시 이체)**:
   - 모든 요청 시 클라이언트에서 UUID `Idempotency-Key` 헤더 자동 생성·전송 (중복 클릭 방지 및 멱등키 표시 옵션)
   - 출금·즉시 이체 시 계좌 PIN 입력 필드 제공
   - 백엔드 에러 응답(`INSUFFICIENT_BALANCE`, `INVALID_PIN`, `ACCOUNT_LOCKED`, `PER_TX_LIMIT_EXCEEDED` 등)을 사용자 친화적인 한국어 알림 배너로 명확히 표시
4. **예약 이체 탭**:
   - 예약 이체 등록 (출금 계좌, 입금 계좌번호, 금액, 예약 일시, PIN, 메모)
   - 내 예약 이체 목록 조회 (`PENDING`, `COMPLETED`, `FAILED`+실패사유, `CANCELED`) 및 `PENDING` 건 취소 버튼
5. **거래내역 & 내 감사 로그 탭**:
   - 선택한 계좌의 복식부기 거래내역 테이블 (일시, 구분 `입금/출금/이체`, 차변/대변, 거래금액, 거래 후 잔액 스냅샷, 상대 계좌 마스킹 번호, 적요)
   - 내 보안·거래 감사 로그 목록
6. **관리자(운영/감사) 전용 탭 (`ROLE_ADMIN` 로그인 시 활성화 또는 탭 제공)**:
   - **원장-잔액 정합성 대사(Reconciliation)**: `[지금 정합성 대사 실행]` 버튼, 3대 불변식 검증 결과(`PASSED` / `MISMATCH_FOUND`, 검사 계좌 수, 거래 수, 불일치 건수) 및 실행 이력 테이블
   - **예약 이체 도래 건 수동 배치 실행**: `[도래 예약이체 즉시 실행]` 버튼 (시연 편의)
   - **계좌 거래정지(`LOCKED`) 해제**: 계좌 ID 입력 후 잠금 해제 실행
   - **전체 감사 로그 조회**: 마스킹된 전체 감사 로그 테이블

## 3. 설정 및 완료 조건
- `frontend/vite.config.ts`: 기본 포트 `5173`, 필요 시 `/api` 프록시 또는 환경변수(`VITE_API_BASE_URL=http://localhost:8080`) 설정.
- `cd frontend && npm install && npm run build`가 타입 에러나 빌드 에러 없이 깔끔하게 성공할 것.
