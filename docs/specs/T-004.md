# T-004 상세 명세: 계좌 관리 (개설, 목록·상세 조회, 소유권 검증, 상태 관리)

## 1. 목표
원화(KRW) 입출금 계좌 개설(PIN BCrypt 해시 저장), 내 계좌 목록/상세 조회, 타인 계좌 접근 차단(소유권 검증), 계좌 해지(`CLOSED`)를 구현한다.

## 2. API 및 기능 명세 (`com.corebank.account`)

### A. 계좌 개설 — `POST /api/accounts`
- 요청: `{ "pin": "1234", "perTxLimit": 10000000, "dailyLimit": 50000000 }`
  - `pin`: 숫자 4~6자리(`^\d{4,6}$`) 필수. 평문 저장 절대 금지, 반드시 BCrypt 해시(`pin_hash`)로만 저장.
  - `perTxLimit`, `dailyLimit`: 미입력 시 기본값 각각 `10,000,000`원, `50,000,000`원 (`BigDecimal`, scale 0, 0 이하 불가).
- 동작:
  - 고유 계좌번호(`110-XXX-XXXXXX` 형식, 중복 체크) 발급.
  - 초기 `balance = 0`, `status = "ACTIVE"`, `is_system = false`, `pin_fail_count = 0`.
  - 감사 로그 기록 (`actionType = "ACCOUNT_CREATE"`, 마스킹된 계좌번호 포함, PIN 절대 미포함).
- 응답 (`201 Created`):
  - `{ "id": 1, "accountNumber": "110-123-456789", "maskedAccountNumber": "110-***-**6789", "balance": 0, "status": "ACTIVE", "perTxLimit": 10000000, "dailyLimit": 50000000, "createdAt": "..." }`

### B. 내 계좌 목록 조회 — `GET /api/accounts`
- 현재 로그인 사용자의 계좌 목록(`user_id = currentUserId`, `is_system = false`)을 생성일 순으로 반환 (`200 OK`).
- 응답에 `pin_hash`는 절대 포함하지 않는다.

### C. 계좌 상세 조회 — `GET /api/accounts/{accountId}`
- 계좌가 없으면 `ACCOUNT_NOT_FOUND`(404).
- **소유권 검증**: 본인 계좌(`account.userId == currentUserId`)이거나 `ROLE_ADMIN`인 경우에만 조회 허용. 타인 계좌 조회 시 `FORBIDDEN_ACCOUNT_ACCESS`(403) 반환.

### D. 계좌 해지 — `PATCH /api/accounts/{accountId}/close`
- 본인 소유 계좌만 가능(타인 계좌는 `FORBIDDEN_ACCOUNT_ACCESS` 403).
- 이미 `CLOSED`이면 `ACCOUNT_CLOSED`(400), `LOCKED`이면 `ACCOUNT_LOCKED`(403).
- 잔액(`balance`)이 `0`원일 때만 `CLOSED`로 상태 전환 가능. 잔액이 0원이 아니면 `INVALID_INPUT`(400, "잔액이 남아있는 계좌는 해지할 수 없습니다") 반환.
- 감사 로그 `ACCOUNT_CLOSE` 기록.

## 3. 완료 조건

- 완료 후 `docs/TASKS.md`의 `T-004` 상태를 `개발 완료`로 바꾸고 `## 작업 기록`에 한 줄 요약을 남길 것.
