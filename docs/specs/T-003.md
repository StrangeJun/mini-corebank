# T-003 상세 명세: 회원·인증·보안(JWT) 및 시스템 시재/관리자 시드

## 1. 목표
D-003([docs/DECISIONS.md](../DECISIONS.md))에 따라 Spring Security + Stateless JWT 인증/인가(`USER`, `ADMIN`), 회원가입/로그인 API, 그리고 복식부기 원장의 상대 계정인 시스템 시재 계좌(`SYSTEM-VAULT`)와 기본 관리자 시드를 구현한다.

## 2. API 및 기능 명세 (`com.corebank.auth`, `com.corebank.user`)

### A. 인증 API (`/api/auth`)
1. `POST /api/auth/signup`
   - 요청: `{ "email": "...", "password": "...", "name": "..." }` (이메일 형식, 비밀번호 최소 8자 검증)
   - 동작: 이메일 중복 시 `DUPLICATE_EMAIL`(409). 비밀번호는 `PasswordEncoder`(BCrypt)로 해시 저장, 기본 권한 `USER`.
   - 감사 로그: `actionType = "USER_SIGNUP"`, `result = "SUCCESS"`, 이메일 마스킹 기록.
   - 응답 (`201 Created`): `{ "id": 1, "email": "...", "name": "...", "role": "USER" }`
2. `POST /api/auth/login`
   - 요청: `{ "email": "...", "password": "..." }`
   - 동작:
     - 실패 시: `AuditLogService.logIndependent(...)`로 `actionType = "LOGIN_FAIL"`, `result = "FAILURE"`를 기록하고 `UNAUTHORIZED`(401) 반환.
     - 성공 시: JWT Access Token 발급(`userId`, `email`, `role` 클레임 포함) 및 `LOGIN_SUCCESS` 감사 로그 기록.
   - 응답 (`200 OK`): `{ "accessToken": "...", "user": { "id": 1, "email": "...", "name": "...", "role": "USER" } }`
3. `GET /api/auth/me`
   - 현재 인증된 사용자 정보(`id`, `email`, `name`, `role`) 반환 (`200 OK`). 미인증 시 `401`.

### B. Spring Security & CORS 설정
- Stateless 세션 정책(`SessionCreationPolicy.STATELESS`), CSRF 비활성화.
- `JwtAuthenticationFilter`: `Authorization: Bearer <token>` 검증 후 SecurityContext에 인증 주체(`userId`, `role`) 설정.
- 접근 제어:
  - `/api/auth/signup`, `/api/auth/login`: `permitAll`
  - `/api/admin/**`: `hasRole("ADMIN")`
  - 그 외 `/api/**`: `authenticated()`
- CORS: React 프론트엔드(`http://localhost:5173`, `http://localhost:3000`)에서 `Authorization`, `Idempotency-Key`, `Content-Type` 헤더 및 `GET/POST/PUT/PATCH/DELETE/OPTIONS` 허용.

### C. 초기 데이터 시드 (`SystemSeedInitializer`)
애플리케이션 기동 시 idempotent하게 확인·생성:
1. 시스템 시재 계좌: `account_number = "SYSTEM-VAULT"`, `is_system = true`, `user_id = null`, `balance = 0`, `status = "ACTIVE"`, `pin_hash = "<BCrypt dummy>"`
2. 기본 관리자 계정: `email = "admin@corebank.com"`, `password = "Admin1234!"` (BCrypt), `name = "시스템관리자"`, `role = "ADMIN"`
