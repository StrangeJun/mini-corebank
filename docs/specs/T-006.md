# T-006 상세 명세: 거래내역 조회 및 감사 로그 조회 API

## 1. 목표
계좌별 거래내역(원장 분개 및 상대 계좌 마스킹 정보, 기간/유형 필터, 페이징) 조회 API와, 본인 또는 관리자(`ADMIN`)용 감사 로그 조회 API를 구현한다.

## 2. API 명세

### A. 계좌별 거래내역 조회 — `GET /api/accounts/{accountId}/transactions`
- **권한**: 본인 소유 계좌(`account.userId == currentUserId`) 또는 `ROLE_ADMIN`. 타인 계좌 접근 시 `FORBIDDEN_ACCOUNT_ACCESS`(403).
- **쿼리 파라미터 (모두 선택)**:
  - `type`: `DEPOSIT` | `WITHDRAWAL` | `TRANSFER` (또는 `entryType`: `DEBIT` | `CREDIT`)
  - `fromDate`, `toDate`: `YYYY-MM-DD` 기간 필터
  - `page` (기본 `0`), `size` (기본 `20`)
- **응답 (`200 OK`)**:
  - 해당 계좌의 `ledger_entries` + `transactions` 조인 결과를 최신순(`createdAt DESC, id DESC`) 페이징 반환:
  - 각 항목: `{ "transactionId": 12, "txType": "TRANSFER", "entryType": "DEBIT", "amount": 20000, "balanceAfter": 20000, "counterpartyMasked": "110-***-**6789", "description": "월세 이체", "createdAt": "..." }`

### B. 감사 로그 조회 API
1. `GET /api/audit-logs/me` (일반 사용자 본인 감사 로그 조회, 최신순 페이징 `page`, `size`)
2. `GET /api/admin/audit-logs` (`ROLE_ADMIN` 전용 전체 감사 로그 조회, `actionType`, `result`, `actorUserId`, `page`, `size` 필터 지원)
   - 응답 항목: `{ "id": 1, "actorUserId": 1, "actionType": "TRANSFER", "targetType": "TRANSACTION", "targetId": "12", "result": "SUCCESS", "maskedSummary": "...", "clientIp": "...", "createdAt": "..." }`
   - 모든 `maskedSummary`에는 평문 비밀번호·PIN·원본 계좌번호 전체가 절대 노출되지 않아야 한다.

## 3. 완료 조건
- 계좌 거래내역 조회(필터·페이징·타인 계좌 403 차단) 및 감사 로그 조회(`USER` vs `ADMIN` 권한 검증) 테스트가 `cd backend && ./gradlew test`에서 통과할 것.
